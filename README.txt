Dressed, version 2: how to put it on her phone

UPDATING (you already have it on GitHub or Netlify)
1. Replace the old files with the 7 files in this folder (index.html, manifest.json, sw.js and the three icon-... pictures, plus this note). On GitHub: open the repository, choose Add file, Upload files, drag all of them in, then Commit.
2. Wait a minute. On her phone open the app, close it fully, and open it again. The new look appears on the second open.
3. Her wardrobe and diary stay as they are. Old photos have no cutout yet: tap an item, switch on Remove background, and Save.

FIRST TIME
1. Try it first: double-click index.html. Anything you add this way stays in that browser only, so use test photos.
2. To install on a phone, the files must be on a web address that starts with https (GitHub Pages or Netlify Drop both work).
3. Android: open the address in Chrome, tap the menu (three dots), then Add to Home screen or Install app. Windows: open it in Chrome or Edge and click the install icon at the right end of the address bar.
4. Each device keeps its own wardrobe. In Settings, Back up wardrobe saves one file, and Restore from a backup loads it on another device.
