Dressed: how to put it on her phone

1. Try it first. Unzip this folder and double-click index.html. It opens in your browser. Anything you add this way stays in that browser only, so use test photos.

2. To install it on a phone, the folder has to be on a web address that starts with https. A free host such as Netlify does this in about five minutes: sign in at app.netlify.com, open Drop, and drag the whole unzipped folder in.

3. On her Android phone, open that address in Chrome, tap the menu (three dots), then Add to Home screen or Install app. On Windows, open it in Chrome or Edge and click the install icon at the right end of the address bar.

4. Each device keeps its own wardrobe. In Settings, Back up wardrobe saves one file, and Restore from a backup loads it on another device. Make a backup now and then, because there is no cloud copy.
